# Contributing

Bug reports, reports from phones and Sailfish OS versions we don't have, and pull requests are all welcome. Most
projects have their own CONTRIBUTING.md with the build and test steps; this one applies where a project has none.

## Reporting a problem

Open an issue with the bug report form. It asks for the Sailfish OS version, the phone and the project's version.
Logs help most, but look through them before you post: they can name apps, accounts and people.

## Changing the code

- One topic per pull request, small commits, a short message in the imperative.
- Anything that runs as root or changes the system needs a check and a way back.
- Nothing personal goes into code, tests, logs or screenshots: no user names, phone numbers or private photos.
- CI must pass. A change that runs on the phone needs a test on one: say in the pull request which phone and Sailfish
  OS version you tried it on.
- Docs, comments and commit messages are in English.
