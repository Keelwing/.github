# .github

The organization-wide files of [Keelwing](https://github.com/Keelwing). GitHub reads this repository by its name:

- `profile/README.md`: the organization's front page.
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`: the defaults for every project that has
  none of its own.
- `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md`: the default issue forms and pull request template.
- `.github/FUNDING.yml`: the Sponsor button.

All of this takes effect only while the repository is public. The members-only front page lives in
`.github-private`; the website and the brand files in `keelwing.github.io`.
