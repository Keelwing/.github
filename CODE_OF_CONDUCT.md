# Code of conduct

Keelwing's issues, pull requests and discussions are for building things for Sailfish OS phones together. Be kind,
stay on topic, and assume good intent; many people here write in a language that is not their first.

Not welcome: harassment, insults or personal attacks, discrimination of any kind, posting someone's private data,
and spam.

Maintainers may edit or remove comments, lock threads and block accounts that break this. To report something
privately, write to d31m05z@gmail.com.
